## Git: коммиты и пуш

После КАЖДОЙ завершённой задачи (партия правок, фикс, рефакторинг —
любой логически цельный кусок работы), если `flutter test` прошёл
полностью зелёным:

1. `git add -A`
2. `git commit` с понятным сообщением по уже сложившемуся стилю
   (например: `rework: <категория> pairs from needs_rework (N пар)`)
3. `git push` в `origin main`

Делай это сама, без запроса подтверждения на каждый пуш — это стандартная
часть завершения задачи, а не отдельное решение, которое нужно каждый раз
согласовывать. Исключение — если `flutter test` не проходит: в этом
случае коммить и пушить нельзя, сначала чинить тесты.
